# PythonWeather
🌤️ Weather Forecast Terminal App

«A beautiful and feature-rich Python CLI Weather App that provides real-time weather updates and a 7-day forecast using live API data.»

---

✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time temperature & "feels like"
- ☁️ Sky condition with emojis
- 🌧️ Rain probability & precipitation data
- 💨 Wind speed & direction
- 💦 Humidity tracking
- 📅 Clean 7-day forecast
- 🎨 Beautiful formatted terminal UI

🚀 Installation

1. Clone the repository

git clone "repo url"

2. Install dependencies

pip install requests

---

▶️ Usage

Run the script:

python pyweather.py

Then enter a city:

🏙️ Enter city name: Kolkata
